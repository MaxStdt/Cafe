# Кафе — жадный алгоритм с динамическим ранжированием

Программа на Python, которая минимизирует суммарные затраты Пети на обеды в кафе за N дней с системой купонов: при покупке более чем на 100 рублей выдаётся купон на один бесплатный обед, который можно использовать в любой последующий день. Программа выводит минимальную суммарную стоимость, количество неиспользованных (K1) и использованных (K2) купонов, а также номера дней, когда Петя пользуется купонами. При равной минимальной стоимости максимизируется K1 (остаток купонов).

## Формат входных и выходных данных

Входной файл: первая строка — целое число N (0 < N ≤ 100), в каждой из последующих N строк — одно целое число (0 ≤ стоимость ≤ 300), стоимость обеда в рублях на соответствующий день. Выходной файл: первая строка — минимальная возможная суммарная стоимость обедов; вторая строка — два числа K1 и K2 (количество неиспользованных и количество использованных купонов соответственно); в последующих K2 строках — в возрастающем порядке номера дней, когда Петя пользуется купонами. Если K2 = 0, строк с номерами дней нет.

## Как работает алгоритм

Используется жадный алгоритм с динамическим ранжированием. Строится Структура1 — дни, отсортированные по убыванию цены (при равенстве — по возрастанию номера дня). Затем дни обходятся слева направо, и для каждого дня находится его ранг среди ещё не обработанных дней (1 = самый дорогой среди оставшихся). Решение принимается по правилу:

~~~
если coupons >= rank(i):   # купонов строго больше, чем будущих более дорогих дней
    тратим купон (день бесплатный), coupons -= 1
иначе:
    платим cost[i]; если cost[i] > 100, coupons += 1
~~~

После обработки день удаляется из Структуры1 (независимо от исхода), ранги оставшихся пересчитываются. Условие `coupons >= rank(i)` эквивалентно `coupons > rank(i) − 1`, то есть купонов строго больше, чем более дорогих будущих дней: после траты на текущий день купонов всё равно хватит на все более дорогие будущие. Это безопасно и даёт оптимальную экономию. Жадный алгоритм тратит купон только когда это безопасно, поэтому естественно оставляет максимум купонов.

Временная сложность: O(N²) при naive-списке (сортировка O(N log N) + N операций поиска и удаления по O(N)); O(N log N) при использовании упорядоченного множества. Память: O(N). При N ≤ 100 naive-реализация работает мгновенно.

## Отладка в VS Code

Файл `.vscode/launch.json` содержит готовые конфигурации. Аргументы (имена файлов) прописаны явно в массиве `args`:

~~~json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Python: пример 1",
            "type": "debugpy",
            "request": "launch",
            "program": "${workspaceFolder}/main.py",
            "console": "integratedTerminal",
            "cwd": "${workspaceFolder}",
            "args": ["tests/input1.txt", "tests/output1.txt"]
        },
        {
            "name": "Python: пример 2",
            "type": "debugpy",
            "request": "launch",
            "program": "${workspaceFolder}/main.py",
            "console": "integratedTerminal",
            "cwd": "${workspaceFolder}",
            "args": ["tests/input2.txt", "tests/output2.txt"]
        }
    ]
}
~~~

**Как отлаживать:**

1. Откройте панель «Run and Debug» (`Ctrl+Shift+D`).
2. В выпадающем списке выберите нужную конфигурацию (например, «Python: пример 2»).
3. Поставьте точку останова в `main.py` (например, на строке с вычислением `rank`).
4. Нажмите `F5`.

**Полезные точки останова:** после чтения ввода (проверить `data`, `n`, `costs`); после сортировки Структуры1 (проверить порядок); внутри основного цикла после вычисления `rank` (проверить `day_num`, `price`, `rank`, `coupons`, `total`, `free_days`); после удаления дня (проверить, что ранги оставшихся корректны); после цикла (проверить `k1 == coupons`, `k2 == len(free_days)`).

**Важно:** не используйте `${command:pickArgs}` в `args` — из-за известной ошибки расширения Python все введённые аргументы попадут в `sys.argv[1]` одной строкой. Прописывайте аргументы явно, как показано выше.

### Виртуальное окружение
